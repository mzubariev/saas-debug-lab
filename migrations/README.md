# Database migrations (Alembic)

Single linear revision history for the **shared** Postgres database:

| Revision | Description    |
|----------|----------------|
| `0001`   | `users` table  |
| `0002`   | `tasks` table (`down_revision`: `0001`) |

ORM definitions live in **`shared/saas_shared/models/`** (`Base`, `User`, `Task`). FastAPI services import those models via thin re-exports under `app/models/`.

## Run with Docker (default)

```bash
cd infra && docker compose --profile core up -d
```

The **`migrations`** service runs `alembic upgrade head` once Postgres is healthy, then exits. **`infra/.env`** must define `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB` (and the compose file sets `POSTGRES_HOST=postgres`).

## Run locally (optional)

From repo root, with `DATABASE_URL` or `POSTGRES_*` matching your database:

```bash
pip install -e ./shared
pip install -r migrations/requirements.txt
export POSTGRES_USER=... POSTGRES_PASSWORD=... POSTGRES_DB=... POSTGRES_HOST=localhost POSTGRES_PORT=5432
cd migrations && alembic upgrade head
```

## New revisions

```bash
cd migrations
alembic revision -m "describe_change"
```

Ensure `env.py` still imports every model that should be autogenerated.
